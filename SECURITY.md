# Security policy

This repository holds images, fonts and two small scripts; it runs no service. Two kinds of report
are useful:

- **A vulnerability in the repository itself** (for example a workflow that could leak something):
  please report it privately. On this repository, open the **Security** tab and choose **Report a
  vulnerability**. Don't open a public issue.
- **Something here that shouldn't be**: an image that infringes someone's rights, or a screenshot that
  shows a real person's account. Report it the same way and it will be removed promptly.

If private reporting isn't available to you, message a maintainer in the
[support server](https://discord.gg/nMJJ8PAcD9) and ask for a private channel, without describing the
problem in public.

This repository holds no secrets. If you find one, that is a vulnerability: report it as above.
